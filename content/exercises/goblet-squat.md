# 小哑铃高脚杯深蹲

- ID：`exercise.goblet-squat`
- 器械：小哑铃 1 只；可徒手替代
- 目标肌群：臀大肌、股四头肌；核心肌群负责稳定
- 高亮区域：臀部、大腿前侧

## 动作步骤

1. 双脚分开约与肩同宽，收紧腹部核心，肩膀后缩下沉。
2. 双手握住一只小哑铃的一端，让哑铃贴近胸口。
3. 臀部缓慢向后并向下，蹲至自己可控的深度；脚跟保持着地，膝盖朝脚尖方向。
4. 短暂停顿后，以臀部和脚底发力站起，站直时夹紧臀部但不要过度挺腰。

## 呼吸与动作感觉

- 下蹲时吸气，站起时呼气。
- 下蹲时髋部和大腿前侧有受控张力。
- 站起时臀部收缩发力，臀部感觉应比腰部更明显。

## 常见错误

| 错误 | 修正 |
| --- | --- |
| 身体过度前倾，重心不稳 | 哑铃贴近身体，胸口保持打开，减少深度直到重心可控。 |
| 弯腰或腰背塌陷 | 收紧核心，保持腰背中立，目视前方自然点。 |
| 膝盖内扣 | 膝盖主动朝脚尖方向打开，脚掌三点稳定着地。 |
| 脚跟离地 | 缩小站距或减少下蹲深度，让脚跟全程贴地。 |

## 重点口令

哑铃贴近身体；臀部向后向下；膝盖朝脚尖方向；脚跟不要离地。

## 关键验收帧

- 准备姿势：双脚约与肩同宽，哑铃贴胸，核心收紧，脚掌稳定。
- 最低点：髋部下沉且腰背中立，膝盖朝脚尖，脚跟仍着地。
- 站直夹臀：身体回到直立，臀部收缩，膝盖不过度后顶。

## 默认节奏

`3-1-1-0`：下蹲 3 秒 → 底部停 1 秒 → 站起 1 秒 → 站立不额外停留。
