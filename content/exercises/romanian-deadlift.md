# 小哑铃罗马尼亚硬拉

- ID：`exercise.romanian-deadlift`
- 器械：小哑铃 2 只；可用徒手髋铰链替代
- 目标肌群：臀大肌、腘绳肌；核心肌群负责稳定
- 高亮区域：臀部、大腿后侧

## 动作步骤

1. 双脚自然站立，双手握住小哑铃放在大腿前侧，拳眼相对。
2. 臀部主动向后推，躯干随髋部前倾，膝盖只做被动的轻微弯曲。
3. 让哑铃贴近腿部下放至小腿中部或自己可控的最低点，保持腰背中立。
4. 短暂停顿后，用臀部发力挺胯起身回到站立，站直后保持核心收紧。

## 呼吸与动作感觉

- 俯身下放时吸气，挺胯起身时呼气。
- 下放过程中下背部保持稳定的张力，不应出现刺痛。
- 最低点臀部和大腿后侧有轻微牵拉感。
- 起身时臀部主动收缩，站直后臀部有挤压感。

## 常见错误

| 错误 | 修正 |
| --- | --- |
| 主动屈膝下蹲，变成深蹲 | 想象臀部向后找墙，减少屈膝幅度，优先保持髋铰链。 |
| 弓背或抬头过度 | 收紧核心，保持头颈与脊柱自然延长。 |
| 哑铃远离身体 | 让哑铃沿大腿和小腿前侧近身移动。 |
| 站起时膝盖超伸或用腰部后仰 | 站直即可，臀部收紧，不要把髋部向前顶过头。 |

## 重点口令

臀部向后，不是向下蹲；背部保持中立；哑铃贴近身体；臀部发力挺胯。

## 关键验收帧

- 站立准备：双脚自然站立，哑铃贴近大腿，核心收紧，肩胛稳定。
- 髋部后移：臀部向后，膝盖微屈，躯干随髋部前倾，哑铃仍贴近身体。
- 最低点：腰背中立，大腿后侧有张力，深度仍在可控范围。
- 挺胯站直：髋部回到站立，臀部收缩，腰部没有后仰。

## 默认节奏

`3-1-1-1`：下放 3 秒 → 最低点停 1 秒 → 挺胯 1 秒 → 站立稳定 1 秒。
