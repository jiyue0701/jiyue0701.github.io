# 后撤交替箭步蹲

- ID：`exercise.reverse-lunge`
- 器械：徒手；可选两只小哑铃
- 目标肌群：前侧腿臀大肌、前侧腿股四头肌；腘绳肌和核心肌群辅助
- 高亮区域：前侧臀部、前侧大腿

## 动作步骤

1. 躯干直立，收紧核心，目视前方，双脚自然分开；可徒手或双手持轻哑铃。
2. 一侧腿向后撤步，前侧脚踩稳，后脚以前脚掌着地。
3. 沉髋屈膝下蹲至自己可控的深度，前侧小腿尽量稳定，膝盖朝脚尖方向。
4. 以前侧腿发力推地，沿原路返回站立，再换另一侧交替。

## 呼吸与动作感觉

- 后撤并下蹲时吸气，前侧腿发力返回时呼气。
- 前侧腿的臀部和大腿前侧承担主要发力。
- 下蹲时前侧腿有受控张力，返回时能感到前脚踩地和臀部发力。

## 常见错误

| 错误 | 修正 |
| --- | --- |
| 后撤距离过短，前侧膝盖压力过大 | 后撤到能让前侧脚掌稳定、前侧小腿相对垂直的位置。 |
| 身体前倾或后仰，重心晃动 | 保持躯干直立和核心收紧，必要时缩小下蹲深度。 |
| 前侧膝盖内扣或脚跟离地 | 前侧膝盖朝脚尖方向，脚跟和脚掌持续踩稳地面。 |
| 后侧腿承担过多重量 | 把主要压力留在前侧脚，后脚只负责辅助平衡。 |

## 重点口令

前侧脚踩稳；后撤再下蹲；膝盖朝脚尖方向；前侧腿发力返回。

## 关键验收帧

- 站立准备：躯干直立，核心收紧，双脚自然分开，重心稳定。
- 后撤落步：后脚落在身体后方，前脚全脚掌稳定，膝盖朝脚尖。
- 底部：前侧小腿相对稳定，髋膝受控下沉，躯干不晃动。
- 返回站立：前侧腿推地返回，身体重新直立，左右动作连续可控。

## 默认节奏

`2-1-1-0`：后撤并下蹲 2 秒 → 底部停 1 秒 → 前脚发力返回 1 秒 → 站立不额外停留。
