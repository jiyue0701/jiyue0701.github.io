## 实验顺序

### E01：身份冲突基线

使用 Reference 1 + Reference 2，不重复输入任何参考图；只改变镜头或表情。目的是确认冲突是否来自参考分工，而不是追求最终画质。

### E02：身体参考隔离

在 E01 通过后加入 Reference 3，只改变身体姿态或训练动作。若出现巨大胸肩、腰线异常或脸部漂移，立即回退并重新裁决身体参考。

### E03：服装状态隔离

固定身份和身体，仅切换正常训练服与“上身裸露 + 不透明短款训练短裤”。验证身份是否保持不变。

### E04：动作控制隔离

固定角色资产，只接入一个动作驱动视频或姿态控制。先验证准备位、最低点、结束位和连续重复，再扩展动作数量。

### E05：模型对照

在相同参考、提示变化、种子范围和验收标准下，对照 4B Distilled 与更大参考编辑方案。结果只以验收表决定，不以模型名称或参数规模决定。

### E06：身体特写矩阵

在身份与身体基线通过后，按 [`shot-matrix-v1.0.md`](shot-matrix-v1.0.md) 建立一组不依赖全身构图的训练素材：

- 胸/肩/手臂：推、拉、弯举或支撑时的肌肉与关节变化；
- 背部：划船、硬拉准备或肩胛控制；
- 腹部：核心收紧、平板支撑或躯干稳定；
- 臀部/股四头肌/腘绳肌/小腿：深蹲、弓步、臀桥和髋铰链；
- 器械与手部：握持、受力和动作路径。

这些特写允许裁切掉脸部或全身，用于 Web App 的动作卡片、肌群高亮和跟练提示。验收只阻断四类内容：全裸、暴露生殖器、女性化身份漂移、武器与束缚情趣配饰；比例漂移、动作错误和画面不清晰属于返工问题。

## 通过后才进入的下一层

```text
Character Bible
  → 参考图分工通过
  → 小样本身份一致性通过
  → 身体与服装状态通过
  → 动作控制通过
  → 身体特写矩阵通过
  → 训练数据集冻结
  → LoRA / Adapter 训练
  → Web App inference_config
```

任何一层失败，都回到上一层修资产或修参考分工，不用 prompt 继续向下掩盖问题。
