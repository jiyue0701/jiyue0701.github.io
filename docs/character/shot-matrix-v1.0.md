## 2. 特写判定

以下情况均属于正常训练素材：

- 画面只出现胸、背、肩、手臂、腹部、臀部或腿部；
- 为了说明发力和动作路径而裁切掉脸部或全身；
- 对臀腿、腘绳肌、股四头肌和小腿使用近景或局部慢动作；
- 叠加肌群高亮、箭头、动作阶段标记或口令字幕；
- 使用局部画面作为动作卡片或训练计划中的辅助素材。

局部特写不要求单独完成身份识别；批量验收时通过同批次的身份参考、角色配置和其他镜头确认角色连续性。

## 3. 四项核心阻断项

任何镜头类型都只因以下情况驳回：

1. 全裸；
2. 暴露生殖器；
3. 女性化身份漂移；
4. 武器与束缚情趣配饰。

体型比例漂移、动作错误、解剖错误、器械穿模、光影不清和身份不稳定属于返工项，不得把“身体特写”本身当成问题。

## 4. 首轮小样本验证

每个候选模型先生成上述 12 个镜头各 1 张，固定身份参考，只改变镜头/动作变量。首轮不做批量动作视频，不做 LoRA 训练。
