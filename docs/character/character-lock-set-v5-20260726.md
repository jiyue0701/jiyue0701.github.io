## 硬锁定字段

- **脸**：第一组确定的动漫游戏脸和成熟、放松的教练表情；只做自然、细微的皮肤纹理，不转为呆板半写实人脸。
- **头发**：黑色至炭黑色，带中性灰色层次/高光；禁止蓝色、棕色或金色主发色。
- **耳朵与耳饰**：真人耳保留；头发上方为黑灰色、柔软毛茸茸的兽耳形装饰；禁止机械、金属、机器耳或生物耳漂移。
- **肤色与材质**：浅暖中性肤色，健身房中性灰黑光影下带轻微暖色；禁止过白、过暗、橙褐化和塑料蜡感。
- **体型**：功能型运动员/专业教练体型，宽肩、自然胸背、精瘦腰线；禁止健美比赛式夸张胸肩和过度切割。
- **颈部**：只保留黑色颈带；禁止项链、吊坠、链条、金属项圈五金或其他颈部饰品。
- **默认场景**：深灰/黑色家庭健身房，柔和中性光，少量暖色补光；不使用过曝白光。
- **默认服装**：黑色训练短裤、黑色训练鞋；上身可根据动作卡片切换训练背心或裸露上身，前提是保持同一身份和体型。

## 初验结果

- 黑灰发色、肤色和颈带规则在单张图内基本可控。
- 但脸部与身体的连续性没有通过用户验收，不能把“头部合格”误认为“角色合格”。
- 颈部已统一为黑色颈带；锁定集不接受项链/吊坠/链条。
- 视图降级为研究素材；在新的身份基准通过前，暂停 LoRA 和角色视频生成。

验收阻断项仍只保留四类：全裸、暴露生殖器、女性化身份漂移、武器与束缚情趣配饰。比例漂移、动作错误、纹理异常和脸部漂移属于生成返工项。
