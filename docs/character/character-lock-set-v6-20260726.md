# 莱欧斯利训练教练：角色锁定集 v6

## 当前结论

候选 A 已作为当前 Web App 角色基线。核心形象必须同时满足：原神莱欧斯利的官方脸部感觉、黑色与中性灰发色、轻暖中性肤色、风格化 3D 动漫游戏渲染，以及功能型运动教练体型。

## 硬锁定项

- 人耳保留；头部左右各一只、共两只对称的毛茸茸黑灰兽耳发饰。
- 兽耳必须是柔软的毛发/耳朵质感，不能是机械耳、金属耳饰，也不能只出现单耳。
- 发色为黑色与中性灰，不使用蓝色主发色。
- 面部沿用官方立绘的成熟、冷静、略带锐度的脸型和眼神；避免呆愣写实脸与幼态脸。
- 肤色为偏浅的暖中性，不做过白或明显偏深的肤色。
- 斜方肌保持克制，肩背有训练感但不夸张；整体为功能型运动员/教练体型。
- 颈部只保留黑色颈带，不添加项链或其他额外颈部饰品。
- 健身场景采用深灰器械、暖中性光影；服装可根据动作在黑色运动背心与不透明黑色训练短裤之间切换。

## 验收标准

每次新生成的角色图先检查：双兽耳是否完整、左右是否同时出现、发色是否黑灰、脸身是否连续、肤色和斜方肌是否回到锁定范围。任意一项不通过，都只能进入候选区，不能进入 Web App 或视频输入。
