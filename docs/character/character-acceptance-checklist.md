# 莱欧斯利居家训练教练｜一致性验收清单

用于图片和视频交付前的人工验收。清单依据主规范 [character-lock-spec.md](character-lock-spec.md)；不替代主规范。

## 判定方式

- `通过`：全部硬锁定项满足，且没有阻断项。
- `返工`：存在可修复的识别、构图、动作或命名问题。
- `驳回`：出现以下任一核心阻断项：全裸、暴露生殖器、女性化身份漂移、武器与束缚情趣配饰。

任何一项“阻断项”不合格，整张图片或整段视频不得交付。

## A. 身份与角色气质

- [ ] 能明确识别为成年男性莱欧斯利方向角色，而不是随机健身模特。
- [ ] 整体气质帅气、可靠、专业、可向往，且处于训练指导语境。
- [ ] 表情是专注、鼓励或克制的轻松，不是挑逗或色情化表演。
- [ ] 没有女性化身份漂移；其他脸部、发型或体型偏差按一致性问题返工。

## B. 发型与脸部

- [ ] 发色为黑蓝至深蓝黑色，带低调冷灰蓝发束，顶部有侧扫蓬松层次。
- [ ] 两侧和后侧保持短削/渐变轮廓，不能变成长发、齐刘海或被帽子遮住。
- [ ] 锐利眉眼、立体鼻梁、清晰下颌线和成熟脸部仍稳定。
- [ ] 眼神服务于训练指导：看镜头、动作目标或学员动作。
- [ ] 没有大幅新纹身、异色眼、极端妆容或未经批准的脸部标志。

## C. 身体表现与安全边界（仅四项阻断项）

上身裸露、短款训练短裤、肌肉展示和身体局部特写均属于允许的训练表达，不因裸露上身或特写本身驳回。

- [ ] 没有全裸；
- [ ] 没有暴露生殖器；
- [ ] 没有女性化身份漂移；
- [ ] 没有武器与束缚情趣配饰。

### C1. 身体特写允许范围

- [ ] 允许胸、背、肩、手臂、腹部、臀部、股四头肌、腘绳肌、小腿、前臂和关节运动特写；
- [ ] 允许局部裁切脸部或全身，作为目标肌群、动作阶段、肌肉高亮或训练卡片素材；
- [ ] 特写能关联到动作、目标肌群、器械、发力过程或技术说明；
- [ ] 特写不要求同时出现完整脸部或全身，但批量验收时必须能通过资产配置确认是同一角色。

体型比例、动作受力、解剖错误、器械穿模和身份不稳定属于返工/质量问题，不得与身体特写混为阻断项。

## D. 配饰与配色

- [ ] 配色以深海军蓝、炭黑、钢灰/银和少量冰蓝为主。
- [ ] 金属/皮革配饰少量、哑光、功能化，默认不超过两类。
- [ ] 没有武器与束缚情趣配饰；普通金属、皮革或训练功能配饰可以保留。
- [ ] 配饰不应覆盖或替代角色身份识别点，也不应抢占训练动作信息。

## E. 镜头与构图

- [ ] 静帧优先 4:5；视频优先 16:9；1:1 仅用于兼容已有参考或明确需求。
- [ ] 默认中景/中近景或必要的全身教学构图；也允许目标肌群局部特写。
- [ ] 镜头服务于动作、目标肌群、器械或训练卡片信息；身体特写本身不构成不合格。
- [ ] 光线自然、干净，能够说明肌肉结构和动作变化。

## F. 训练环境与动作（质量项）

- [ ] 环境能明确读作整洁、安全、可使用的居家训练区。
- [ ] 至少有训练垫、哑铃、弹力带、训练凳或类似可信器械中的一类。
- [ ] 地面清晰、动作范围充足，没有明显绊倒危险或器械穿模。
- [ ] 动作技术和受力方向可信，姿态体现教练示范或指导目的。
- [ ] 优先使用居家训练区；其他环境按产品场景质量评估，不因环境本身或身体特写自动驳回。

## G. 视频专属检查

- [ ] 发型、脸部、肤色、体型和短裤覆盖在首帧、中段、尾帧一致。
- [ ] 动作连续，手指、关节、器械、短裤腰头和配饰没有闪烁、穿模或形变。
- [ ] 镜头移动、局部特写和慢动作均服务于动作、肌肉变化或技术说明，不得触发 C 节四项阻断项。
- [ ] 汗水、呼吸和肌肉变化连续自然，没有突然增肌、缩身或年龄变化。
- [ ] 视频中任何一帧都满足 C 节全部阻断项。

## H. 文件与命名

- [ ] 文件名使用固定角色 ID `leosley_coach`。
- [ ] 文件名只使用小写 ASCII、下划线和规定字段，无中文、空格和尾部多余下划线。
- [ ] 静帧符合 `leosley_coach_{scene}_{action}_{shot}_{variant}_{seq5}.png`。
- [ ] 视频符合 `leosley_coach_{scene}_{action}_{shot}_take{take2}_{yyyymmdd}.mp4`。
- [ ] 序号、take 和日期格式正确，文件内容与文件名字段一致。
- [ ] 源参考静帧保持原路径和原文件名，不被覆盖或改写。
