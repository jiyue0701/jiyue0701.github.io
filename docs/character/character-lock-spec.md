## 3. 发型规范

- 主色为黑蓝至深蓝黑色，带低调冷灰蓝高光/发束；顶部保持有方向性的蓬松层次，两侧与后侧为短削/渐变，露出清晰轮廓。
- 刘海向角色右侧（画面通常为左侧）扫过额头，保留几束自然尖束，避免整齐齐刘海或长发遮脸。
- 发量要有空气感和运动后的轻微动态；可因汗水略微贴合，但不能改变侧削结构。
- 禁止黑发、金发、彩虹染、长辫、马尾、帽子遮住发型、夸张发饰或大面积发胶亮面。

## 4. 脸部与表演规范

- 保留成熟男性的锐利眉眼、清晰下颌线、立体鼻梁和略带压迫感但不敌意的专注神情。
- 肤色保持浅色、冷中性、接近官方形象；可以有运动后的轻微泛红或汗光，但不可变成深棕、橙色或过度晒黑，也不可过度磨皮或塑料质感。
- 眼神主要看镜头、看动作目标或看学员动作；表情传达“我能带你完成这组训练”，而不是暧昧凝视。
- 允许：中性专注、微笑鼓励、示范时的严肃、完成动作后的轻松。
- 风格优先：保持专注、鼓励和训练指导状态；明显女性化身份漂移进入核心阻断项，其余表情偏差按风格返工处理。

## 5. 服装、裸露边界与配饰

### 5.1 当前服装锁定

- 上身不穿衣物，完整呈现肩、胸、背、腹、手臂的训练体态；这是“训练成果展示”，不是裸体展示。
- 下身默认穿当前方向要求的最短实用训练短裤；短裤长度、版型、材质和颜色可以作为服装状态单独调整。
- 训练动作和臀腿特写可以展示臀部、股四头肌、腘绳肌和小腿的训练状态；唯一与身体暴露直接相关的核心阻断项是生殖器暴露。
- 服装读感、光影、汗光和肌肉状态作为角色风格与产品质量项验收，不与身体特写混为安全阻断项。
- 训练鞋、护腕、毛巾和水壶可出现，但不能喧宾夺主；颈部只保留黑色颈带，不添加项链、吊坠或链条。

### 5.2 配色

| 色彩角色 | 建议色值 | 用途 |
| --- | --- | --- |
| 深海军蓝 | `#182A46` | 短裤主色、器械或背景点缀 |
| 炭黑 | `#20242C` | 腰头、训练鞋、皮革腕带 |
| 钢灰/银 | `#AEB8C4` | 金属扣、器械、少量装饰线 |
| 冷灰蓝 | `#71839A` | 发束高光、局部反光 |
| 冰蓝 | `#6C91B4` | 极少量识别性点缀 |
| 浅冷中性肤色 | 以官方身份参考和当前 v3 基准为准 | 肤色、运动后轻微泛红；不能整体压暗 |

默认采用深海军蓝或炭黑短裤，配少量钢灰/银色功能细节。禁止荧光大面积撞色、透明材质、动物纹、露骨文字或大幅品牌 Logo。

### 5.3 金属/皮革配饰上限

- 默认最多同时出现 2 类小型配饰：例如黑色皮革腕带 + 哑光金属扣。
- 配饰应有训练功能或结构作用，尺寸小、表面哑光，不产生 BDSM、束缚、军械或情趣联想。
- 禁止大面积链条、项圈、胸带、皮革 harness、非角色固定发型兽耳装饰的夸张耳饰、武器、尖刺和会遮挡身体识别点的饰物；固定发型兽耳装饰必须是柔软毛茸茸的黑灰材质，不得做成机械、金属或塑料结构。

## 6. 体型、姿态与动作

- 体型基准：高挑、宽肩、窄腰、长四肢、胸肩背和手臂有明确训练线条，腹部紧实但不追求不自然的八块腹肌刻画。
- 保持成年运动员的真实重心和关节关系；动作优先体现力量控制、技术正确和可教学性。
- 推荐动作：哑铃弯举、深蹲、硬拉准备、俯卧撑、平板支撑、弓步、拉力带训练、热身拉伸和动作纠正。
- 允许汗水、呼吸起伏、肌肉收缩和少量训练疲态；禁止伤口、血迹、极端脱水、病态消瘦或超现实肌肉膨胀。
- 允许以胸、背、肩、手臂、腹部、臀部、股四头肌、腘绳肌和小腿等训练区域作为教学特写；特写应服务于动作、目标肌群、发力过程或技术提示。
- 身体特写不要求同时出现完整脸部或全身；只要角色身份、服装状态和训练语境仍可由资产配置或镜头上下文确认即可。

## 7. 镜头与画面语言

### 7.1 默认镜头

- 静帧默认 4:5；视频默认 16:9。1:1 可作为已有参考静帧的兼容比例。
- 默认中景或中近景，约胸部至大腿上段；示范动作需要时可用全身，但必须保留训练器械和安全空间。
- 允许训练目标肌群特写：胸、背、肩、手臂、腹部、臀部、股四头肌、腘绳肌、小腿，以及握持器械和关节运动细节。
- 允许局部构图裁切脸部或全身；局部画面可以单独作为动作讲解、肌肉高亮、发力阶段或 Web App 卡片素材。
- 机位以视线高度或略高于胸口为主，使用自然的三分之四正面、正面或侧面；镜头要服务于动作教学和角色识别。
- 采用自然景深和中性透视，避免广角拉伸和会误导动作/身体比例的畸变；近距离镜头本身不构成驳回理由。
- 灯光以家庭健身区的自然窗光、柔和顶光或干净的训练灯为主；保留肩胸轮廓但不使用油腻高光或戏剧化红光。

### 7.2 禁止的镜头意图

- 身体、肌肉和局部训练区域特写均可使用，不因“特写”自动驳回。
- 只有出现全裸、暴露生殖器、女性化身份漂移、武器与束缚情趣配饰时，才属于本规范的核心阻断项。

## 8. 训练环境

- 默认环境为整洁、安全、真实可用的居家训练区：客厅一角、家庭健身房、开放式房间或带窗训练空间。
- 推荐元素：训练垫、哑铃、壶铃、弹力带、可调训练凳、收纳架、水壶、毛巾、自然窗光和适度生活痕迹。
- 空间应有清晰地面、足够动作范围、无绊倒物；器械尺度和受力方向要可信。
- 背景可轻度虚化，但不能把环境虚化到看不出“居家训练”。
- 允许：不同房间布局、晨间/傍晚光线、少量木色或灰色家具、不同器械组合。
- 环境优先保持训练语境和可用性；卧室、浴室、换衣间、夜店等环境属于场景质量返工项，不作为身体特写的核心阻断项。

## 9. 允许变化与质量返工

### 9.1 允许变化

- 训练动作、动作阶段、站姿/跪姿/卧姿和教练手势。
- 正面、三分之四、侧面及必要的全身/中景构图。
- 家庭训练区的布置、器械种类、自然光时间和少量背景生活物件。
- 短裤的深海军蓝/炭黑主色、窄幅钢灰拼色、腰头或小口袋等功能性细节。
- 一条腕带、一个功能性金属扣等少量小配饰。
- 运动后的汗光、轻微泛红、发丝凌乱和表情强度。

### 9.2 一致性返工项

- 改变黑色至炭黑色侧削短发、灰色发束、固定发型兽耳装饰、浅色皮肤、锐利成熟脸部、成年男性身份和核心体型比例；把图1的脸部画风漂移成图2式半写实脸，作为质量返工项。
- 训练状态、镜头、动作或局部特写不能让角色身份与资产配置无法确认。
- 身体结构、动作受力、器械关系、发型、脸部和训练服装出现明显漂移时，作为质量问题返工，不与身体特写混同。
- 未经单独批准的大纹身、明显疤痕、异色眼睛、异色发根、极端妆容或新身份标志。
- 解剖错误、肢体数量错误、手指错误、器械穿模、汗液/水面不合理和视频中身份漂移。

### 9.3 四项核心阻断项

- 全裸；
- 暴露生殖器；
- 女性化身份漂移；
- 武器与束缚情趣配饰。

## 10. 图片与视频命名规则

### 10.1 通用字段

- 角色 ID 固定为 `leosley_coach`，沿用现有素材命名中的项目资产 ID。
- 所有新文件使用小写 ASCII、下划线分隔，不使用空格、中文、括号或特殊符号。
- `scene` 使用稳定场景词，例如 `homegym`、`livingroom_gym`；`action` 使用动作词，例如 `curl`、`squat`、`plank`。
- `shot` 使用 `wide`、`medium`、`close`、`threequarter` 等受控词；`variant` 使用简短可读的外观/灯光变体。
- 序号固定 5 位，从 `00001` 开始；视频 take 固定 2 位，从 `01` 开始。
- 日期统一 `YYYYMMDD`；不要把模型名、随机种子或运行日志塞进角色主文件名，可写入旁车元数据。

### 10.2 静帧

格式：

`leosley_coach_{scene}_{action}_{shot}_{variant}_{seq5}.png`

示例：

- `leosley_coach_homegym_curl_medium_neutral_00001.png`
- `leosley_coach_livingroom_gym_plank_threequarter_warm_00002.png`
- `leosley_coach_homegym_squat_wide_daylight_00003.png`

### 10.3 视频

格式：

`leosley_coach_{scene}_{action}_{shot}_take{take2}_{yyyymmdd}.mp4`

示例：

- `leosley_coach_homegym_curl_medium_take01_20260726.mp4`
- `leosley_coach_livingroom_gym_plank_threequarter_take02_20260726.mp4`

旧素材如 `leosley_coach_flux2_noasync_00001_.png` 只作为历史来源保留；新交付不复制其尾部多余下划线，也不以旧命名规则继续扩展。
