## 功能验收

- 首页角色图与文案分栏，角色资产状态显示为已锁定。
- 计划页按肌群一级分类、器械二级筛选；预设计划可添加到计划库，用户计划支持改名、编辑、删除。
- 已覆盖徒手、椅子辅助、哑铃三类器械，以及飞鸟、卧推、硬拉、划船等动作。
- 训练页默认只有跳过、暂停；动作结束后自动进入休息或下一动作，休息结束自动继续。
- 训练弹层使用动作媒体和海报兜底；标题、计数、计时和控制区与人物画面分离，动作详情通过卡片入口打开。

- 日历记录完成训练；资料页支持 JSON 备份导出和导入；支持 PWA 安装入口。

GitHub Pages 采用当前统一发布账号的用户站点仓库 `jiyue0701.github.io`，这样应用内的根路径媒体 `/media/...` 在 Pages 环境下仍然有效。发布源已切换为 GitHub Actions，不使用 `main` 根目录的经典 Jekyll 渲染；部署由 `.github/workflows/deploy-pages.yml` 构建并发布 `app/dist`。
