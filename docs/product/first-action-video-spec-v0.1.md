# 首个动作视频｜高脚杯深蹲 v0.1

## 交付单元

只制作一个完整动作：小哑铃高脚杯深蹲。第一版不做多动作串联，不做 15 分钟长视频；App 负责循环、倒计时、轮次和完成状态。

## 镜头

- 竖屏 9:16，固定正面三分之四机位；
- 全身、双脚、哑铃和地面安全空间完整可见；
- 中性灰黑健身房光影，清晰说明膝盖、髋部和脚跟；
- 角色媒体必须同时通过官方身份、头身连续性、动作和服装验收。

## 动作关键帧

1. 准备：双脚约与肩同宽，哑铃贴胸，核心收紧。
2. 最低点：臀部向后向下，膝盖朝脚尖，脚跟着地，腰背中立。
3. 站直：脚底和臀部发力，站直但不锁死膝盖。

## 播放层

- 默认动作窗口：45 秒；
- 默认目标次数：10 次；
- 口令：准备、下蹲吸气、膝盖朝脚尖、第 N 次、站起呼气、完成；
- 高亮区域：臀部、大腿前侧；
- 媒体通过前，使用页面媒体槽位，不将拒收素材交付给用户。
