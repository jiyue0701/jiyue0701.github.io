# 首批臀腿动作与 15 分钟训练计划

## 交付范围

本批包含四个首批动作：

1. [高脚杯深蹲](../content/exercises/goblet-squat.md)
2. [小哑铃罗马尼亚硬拉](../content/exercises/romanian-deadlift.md)
3. [后撤交替箭步蹲](../content/exercises/reverse-lunge.md)
4. [小哑铃臀桥](../content/exercises/glute-bridge.md)

每个动作同时提供 JSON 数据和 Markdown 标准卡。JSON 是结构化内容的主数据，Markdown 用于人工审阅；两者保持同一动作口径。

## 计划概览

| 阶段 | 时长 | 内容 |
| --- | ---: | --- |
| 热身 | 3:00 | 髋关节环绕、膝关节热身、蹲姿动态髋部活动、徒手臀桥预热 |
| 器械与空间准备 | 0:30 | 准备小哑铃、瑜伽垫并清出活动空间 |
| 主训练第 1 轮 | 3:45 | 四个动作，每个动作 45 秒，动作间休息 15 秒 |
| 轮间休息 | 0:45 | 调整呼吸和动作幅度 |
| 主训练第 2 轮 | 3:45 | 四个动作，每个动作 45 秒，动作间休息 15 秒 |
| 结束前休息 | 0:15 | 缓慢起身，准备收操 |
| 结束收操 | 3:00 | 髋屈肌、大腿后侧、臀部四字拉伸 |
| **合计** | **15:00** | **约 15 分钟** |

主训练动作顺序固定为：高脚杯深蹲 → 小哑铃罗马尼亚硬拉 → 后撤交替箭步蹲 → 小哑铃臀桥。

## UI 状态约束

计划是计时型内容。UI 可以展示倒计时、动作提示和休息提示，但持久化记录只允许以下三种状态：

- `completed`：完成该阶段或动作窗口
- `skipped`：跳过该阶段或动作窗口
- `extra`：在计划之外主动加练

不得记录逐组重量、逐组次数、每组重量变化或每组次数变化。动作窗口使用时长和节奏提示，不把次数写入计划数据。

## 验收口径

- 四个动作均有步骤、呼吸、动作感觉、常见错误、重点口令、目标肌群、高亮区域、关键验收帧、默认节奏和正式视频/音频/海报。
- 关键验收帧覆盖准备、动作过程和结束位置，便于后续视频人工验收。
- 正式素材均指向 App 的 30 FPS WebM/MP4、动作海报和纯数字计数音频，不把 Keep 页面媒体纳入正式 App 资源。
- 计划总时长为 900 秒，UI 状态集合固定为 `completed`、`skipped`、`extra`。
